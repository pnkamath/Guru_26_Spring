# What felt easy?
Overall, printing to standard output was pretty straightforward. We also found that working with variables, both storing to them and printing them, was also pretty easy. The printing of the collections, collect and reject tasks were also easy. While they were unintuitive at first, the select and inject:into: tasks were also easy after consulting the learn.st file linked on the class page.

# What felt hard?
Working with the objects in part 3 took a while to get used to. While we found it easy to write the body of the helper function, getting to that point took a lot of trial and error. Most of these errors came from the differences between how most languages we are used to working with, like Java and Python, and Smalltalk define classes and subclasses. Once we got used to the syntax and language changes, working with the objects got a bit easier to understand.
